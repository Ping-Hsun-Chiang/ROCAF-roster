# EXP-002：Jitter 單位修正

- **日期：** 2026-10-25
- **結果：** ✅ 採用
- **對應 commit：** `86ef9cc`

## 動機

第一版情境模擬中，一般情境的月結算偏差 SD 約 0.8 節，最差的人差到 2～3 節。
檢查程式後發現，隨機擾動（jitter）直接加在公平值（節／上班天）上，預設 0.3。
公平值的分母會隨月份累積：上班 20 天時，0.3 的擾動等於 **6 節**的差距，
讓「差了好幾節的人」仍被視為差不多而隨機排序。

## 假設

把 jitter 改以「節」為單位（再除以上班天數），讓擾動代表的節數不隨月份放大，
可顯著降低月結算偏差，同時保留同分者之間的隨機輪替。

## 方法

- 工具：`npm run simulate`（第一版，5 seeds，8 個非結構性情境）。
- 比較舊版（公平值單位 0.3）與新版（節單位 1.0／0.5／0.2）。
- 指標：月結算偏差 SD（seed 平均）／ 最大偏差（最差的一人）。

## 結果

| 情境 | 舊版 | 1.0 節 | **0.5 節（採用）** | 0.2 節 |
| --- | --- | --- | --- | --- |
| S1 標準單位 | 0.79 / 2.0 | 0.52 / 1.7 | **0.47 / 1.0** | 0.50 / 1.4 |
| S2 小單位 | 0.84 / 2.4 | 0.41 / 1.0 | **0.42 / 1.1** | 0.35 / 0.6 |
| S3 大單位 | 0.80 / 2.1 | 0.43 / 1.5 | **0.36 / 1.0** | 0.35 / 1.1 |
| S8 週末大休 | 0.94 / 3.2 | 0.63 / 1.7 | **0.66 / 2.2** | 0.64 / 2.2 |
| S9 長假 | 0.77 / 2.0 | 0.50 / 2.0 | **0.48 / 1.2** | 0.46 / 1.6 |
| S10 中途報到／離營 | 0.79 / 1.8 | 0.46 / 1.2 | **0.39 / 1.0** | 0.38 / 1.0 |
| S11 出勤劇烈波動 | 0.89 / 3.2 | 0.79 / 2.7 | **0.76 / 2.4** | 0.78 / 2.4 |
| S12 固定輪休 | 0.87 / 2.2 | 0.38 / 0.8 | **0.36 / 0.8** | 0.38 / 1.0 |

### 負面結果

- S2 小單位每月空缺從 1.6 格變為 2.4 格（5 seeds，差異可能是雜訊，尚未檢定）。
- S8、S11 改善有限：出勤人數每天差異大時，人少的日子每人都得多站，屬結構性限制。

### 重新驗證（30 seeds，ablation study）

詳見 [`results/ablation.md`](results/ablation.md) 與 [EXP-004](EXP-004-statistical-validation.md)。

- 偏差 RMS：現行 0.36～0.68 節 vs 舊版 0.79～0.91 節，9 個情境全部 p < 0.001。**原始結論被確認。**
- 灰色偏差也同時改善，9 個情境中 8 個達統計顯著。
- S2 空缺：現行 2.2 vs 舊版 2.5 格／月，原本擔心的「空缺增加」在 30 seeds 下**沒有出現**，
  5 seeds 時看到的差異應是雜訊。

## 結論與後續

- 採用 0.5 節。0.2 節的公平性相近；選擇 0.5 是為了保留較多同分者之間的隨機輪替。
  這個取捨**尚未量化**（例如「連續幾天被排在相同班次」的指標），是可能的後續實驗。
- 第一版模擬只有 5 seeds、沒有統計檢定，這是促成 [EXP-004](EXP-004-statistical-validation.md) 的原因。
